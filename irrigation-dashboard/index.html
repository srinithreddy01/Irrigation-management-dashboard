          Help & Support

          How this dashboard works

          Monitor, analyse, recommend, control and save water

          1. 1

            Monitor

            Simulated sensors on Field A, Field B and Field C report soil moisture, temperature, humidity and tank level every few seconds.

          2. 2

            Analyse

            Charts summarise soil moisture trends and daily water consumption, with a farm health score.

          3. 3

            Recommend

            When moisture drops below your threshold, the dashboard suggests a duration and water estimate.

          4. 4

            Control

            Start or stop the pump in manual mode, or let automatic mode react to the threshold rule.

          5. 5

            Save water

            Schedules and thresholds keep consumption in view so water is only used when it is needed.

          Privacy Policy

          Last updated: 18 September 2026

          1. About this policy

          AquaFarm is a demonstration smart irrigation dashboard. This policy explains what information the dashboard processes when you open it in a browser.

          2. Information we process

          The dashboard does not require an account and does not transmit personal information to a server. The following values are stored locally in your browser using localStorage:

          • Irrigation settings such as the soil moisture threshold, tank capacity, unit preference and automatic irrigation toggle.
          • Schedules you create, activity records generated during your session, alert read states and export files you request.

          3. Simulated sensor data

          Soil moisture, temperature, humidity, tank level, water consumption and weather values are generated in the browser for demonstration purposes. They do not describe any real field.

          4. Analytics

          The dashboard records anonymous interaction events (such as refreshing readings, toggling the pump or saving settings) in memory for demonstration. No analytics cookies or third-party trackers are used.

          5. Your control

          You can clear all stored values at any time with Clear saved data in Settings, which removes everything this dashboard has saved in your browser.

          6. Cookies

          This dashboard sets no cookies. Local storage is used only for the functionality described above.

          7. Contact

          Privacy questions: support@aquafarm.example.com (demonstration address).
